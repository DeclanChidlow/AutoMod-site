Views a user's global and server pronouns. If no user is specified, the command returns your own pronouns. You can also use it in reply to a message to get the pronouns of its author.

Note that Stoat only allows users to change their own pronouns, so AutoMod cannot set them.

Usage: `/pronouns [@user]`

Aliases: `pronoun`

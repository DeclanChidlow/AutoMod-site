Moderation commands exist to help in enforcing server rules.

Commands in this category can be used by users with the required permission listed on each command's page, as well as by moderators. Users are considered moderators if they have the `Manage Messages` or `Manage Server` permission, or if they have been configured as a server moderator in [the dashboard](/docs/automod/dashboard).

Manage a user's server-specific nickname. If no nickname is provided, the user's nickname will be reset. Moderators can manage other users' nicknames, while any user with the Change Nickname permission can use the command to change their own.

Usage: `/nick <user> [nickname]`

Aliases: `setnick`

Required permissions: `Manage Nicknames` to manage others' nicknames; `Change Nickname` to change your own.
